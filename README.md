# Trasmitir

Aplicación para Android optimizada para Motorola diseñada para escanear y transmitir la pantalla del celular a Smart TVs de forma universal.

## Características
* Escaneo de dispositivos compatibles en la red local.
* Duplicación de pantalla mediante captura en tiempo real (`MediaProjection`).
* Soporte multiprotocolo (Chromecast, DLNA, Servidor Web local).

## Requisitos de compilación
* Android Studio
* SDK mínimo recomendado: Android 7.0 (API 24) o superior.
